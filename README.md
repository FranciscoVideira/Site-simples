# Sweet Sabor — Interactive Web Application

A responsive web application developed for **Pastelaria Doce Sabor**, combining traditional web architecture with modern React components to handle interactive user features.

---

## 📌 Project Overview

This project focuses on building a clean, modern, and user-friendly web interface for a confectionery shop. It demonstrates the integration of core front-end web technologies (HTML5, CSS3) with **React** to handle dynamic client-side functionality, such as contact forms and interactive UI components.

---

## ✨ Key Features

- **Responsive Layout:** Structured UI built with HTML5 and custom CSS3 for cross-device compatibility.
- **Dynamic React Components:** Embedded React elements to manage real-time user interactions and state.
- **Interactive Form Handling:** Client-side validation and dynamic input handling using React hooks.
- **Modular Codebase:** Clean separation of concerns between structure, styling, and application logic.

---

## 🛠️ Tech Stack

- **Front-End:** HTML5, CSS3, JavaScript (ES6+)
- **Library Framework:** React
- **Version Control:** Git & GitHub
